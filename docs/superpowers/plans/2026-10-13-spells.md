# Spells Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Hover a spell (spell book first; any real spell tooltip), press Ctrl+C once, and the popup shows the spell's comments. It works in WoW Forever first and TBC Anniversary too. Then version 0.3.0, rebuild the program, and push the feature branch.

**Architecture:**
- **The add-on** reads a spell from the tooltip. In Forever that's `TooltipUtil.GetDisplayedSpell`, with tooltip data of type Spell. In TBC it's `tooltip:GetSpell()`, taking the last number among its returns.
- **Readying:** the readied copy also hooks the spell tooltip, through `TooltipDataProcessor` (Spell) or `OnTooltipSetSpell`.
- **The app:** links accept `spell=`. A small spell reader takes the heading, the Gatherer data (type 6) and the comments. The popup shows the comments, as for items and quests.

**Tech Stack:** Lua 5.1 + pytest/lupa (add-on); Electron 44, TypeScript 7, Vitest 5, happy-dom (app).

**Spec:** `docs/superpowers/specs/2026-10-13-spells-design.md`.

## Global Constraints

- **Forever first, TBC too.** Every client-specific call is guarded by an existence check: `TooltipUtil.GetDisplayedSpell`, `tooltip.GetSpell`, `C_Spell.GetSpellTexture`/`GetSpellName`, `GetSpellTexture`, `GetSpellInfo`, `TooltipDataProcessor`, `HasScript("OnTooltipSetSpell")`.
- **Lookup order:** items, then spells, then quests.
- **The link:** `https://www.wowhead.com/[site/][lang/]spell=<id>`.
- **One-press rules unchanged:** off in combat, while typing, and over action bar buttons. The let-go rule stays.
- **Texts:**
  - "Look up hovered item, quest or spell";
  - "Hover over an item, quest or spell to look it up on Wowhead.";
  - "Wowhead lists no comments for this spell.";
  - fallback names "Spell 27019".
- **The popup:** a spell name is white (quality 1). Nothing in a spell popup is clickable.
- **Release:**
  - Version 0.3.0 in `app/package.json`, `app/package-lock.json` and the `.toc`.
  - Rebuild `app/release/Wowhead Gatherer 0.3.0.exe`.
  - `git push origin feat/wowhead-gatherer`, never forced.
- **Commands:**
  - Add-on: `.venv/Scripts/python -m pytest tests -q` (repo root).
  - App: `npx vitest run` and `npm run typecheck` (from `app/`, with `export PATH="/c/Program Files/nodejs:$PATH"`).
  - Electron: `env -u ELECTRON_RUN_AS_NODE`.
  - **Edits containing backslashes** use the editor, not shell scripts, which have dropped backslashes before.
- **Commits:** Conventional Commits, each ending with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

These are the inputs the spec implies but its happy paths don't exercise. Each one has a test in the task named.

**`Lookup.lua`.**
- Replace the body of `ns.GetHoveredItem` with a shared helper, and add the spell reader and spell helpers. After `ReadTooltip`, add:

```lua
-- Returns the spell ID and name a tooltip is showing, or nil. Mainline-family
-- clients (WoW Forever) read the tooltip's data through TooltipUtil. TBC asks the
-- tooltip: GetSpell() returns name, spellID (older clients: name, rank, spellID),
-- so the ID is the last number.
local function ReadSpell(tooltip)
    if TooltipUtil and TooltipUtil.GetDisplayedSpell and tooltip.IsTooltipType then
        local name, spellID = TooltipUtil.GetDisplayedSpell(tooltip)
        if spellID then
            return spellID, name
        end
    end
    if tooltip.GetSpell then
        local name, second, third = tooltip:GetSpell()
        local spellID = tonumber(third) or tonumber(second)
        if spellID then
            return spellID, name
        end
    end
end

-- Reads the tooltips a lookup looks at, in order, with read. ItemRefTooltip
-- (opened by clicking a chat link) stays up after the cursor leaves it, so it
-- only counts while hovered.
local function ReadHoveredTooltip(read)
    local candidates = {
        { tooltip = ItemRefTooltip, needsMouse = true },
        { tooltip = GameTooltip },
    }
    for _, candidate in ipairs(candidates) do
        local tooltip = candidate.tooltip
        if tooltip and tooltip:IsShown() and (not candidate.needsMouse or tooltip:IsMouseOver()) then
            local id, label = read(tooltip)
            if id then
                return id, label
            end
        end
    end
end
```

import { pickComments } from './comments';
import { pageNames } from './itemInfo';
import { readHeading } from './questPage';
import { parseItemPage } from './wowheadPage';
import type { ZoneNames } from './zones';

/** Wowhead's type number for spells in WH.Gatherer.addData. */
const SPELL_TYPE = 6;

/** Everything the popup shows for a spell, or null when the page doesn't have the spell's data. */
export function buildSpellInfo(spellId: number, html: string, zones: ZoneNames): SpellInfo | null {
  const page = parseItemPage(html);
  const spell = page.gatherer.get(SPELL_TYPE)?.get(spellId);
  if (!spell) return null;
  const { comments, total } = pickComments(page, pageNames(page, zones));
  return {
    kind: 'spell',
    // The heading is in the page's language; the Gatherer data can be in English.
    name: readHeading(html) ?? spell.name,
    quality: 1,
    icon: spell.icon ?? '',
    comments,
    commentTotal: total,
  };
}
